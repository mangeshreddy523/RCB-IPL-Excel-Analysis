# RCB IPL Excel Analysis Dashboard

## Project Overview

This project analyzes Royal Challengers Bengaluru (RCB) IPL match data using Microsoft Excel.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- KPI Analysis
- Match Performance Analysis

## Key Analysis

- RCB match performance
- Wins and losses
- Player of the Match analysis
- Venue-wise performance
- Opponent-wise performance
- Season-wise analysis
